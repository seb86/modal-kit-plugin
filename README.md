# Modal Kit

Modals made of blocks for the WordPress block editor: popups, slide-ins, bars, drawers, full-screen takeovers, bottom sheets, inline panels and a video lightbox.

Modal Kit adds one block, Modal, and you build everything inside it with core blocks. Modals pick up your theme's colors, fonts and spacing from `theme.json`, use the native `<dialog>` element, set no cookies, and keep working on sites exported as static HTML.

**Status:** beta.

The full feature list is in [`readme.txt`](readme.txt).

Requires WordPress 6.8+ and PHP 7.4+.

## Installing

Modal Kit is on its way to the WordPress.org plugin directory. Until it's listed, download the zip from [Releases](https://github.com/seb86/modal-kit-plugin/releases) and upload it in **Plugins → Add New Plugin → Upload Plugin**.

## Feedback

Modal Kit is in beta, so feedback from real sites decides what comes next. If something doesn't work as you expect, or you have an idea, please [open an issue](https://github.com/seb86/modal-kit-plugin/issues).
